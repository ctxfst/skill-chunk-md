# CtxFST 中文說明

> 狀態：**格式草案，尚未實作**。資料收集方式另案處理，本目錄只定義格式。
> 英文版在中文版核對完成後再改寫。

## CtxFST 是做什麼的

CtxFST 用來**面對最新資料，追蹤狀態的變化**。例如每天收集化妝品與產婦市場的資訊，分辨哪些產品正在變熱門、哪些在退燒、哪些價格或規格變了。

它不是知識庫搜尋工具。它回答的問題是：

- 今天和昨天比，**什麼變了**？
- 這個變化有幾個**獨立來源**支持？證據在哪裡？
- 哪些是真的熱門，哪些只是單一來源的雜訊？

## 一句話看懂流程

```
收集 → 觀測 → 標註（相關性、實體、去重）→ 每日狀態 → 變化 → 每日報告 → 你的回饋
```

- **觀測**是原始資料，收進來就不再改。
- **標註、狀態、變化**都由程式從觀測算出來，隨時可以重算。
- **關注定義、實體表、回饋**是人寫或人確認的，程式只會照你的標記追加，不會自己改寫。

## 與先前版本的關係

- **v2（實體圖）**：保留在 `legacy-entity-graph` 分支。它的實體是為了「找相關筆記」，這裡的實體是為了「追蹤同一個東西隨時間的變化」，用途不同。
- **v3（形狀卡）**：從 v3 留下的是**探針加回饋**：用你確認過的例子和退回的例子，判斷一筆資料相不相關。形狀卡本身不在這個格式裡。
