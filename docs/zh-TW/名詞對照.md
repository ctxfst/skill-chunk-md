# 名詞對照

文件用中文名詞，檔案裡的欄位名稱用英文。程式兩種資料夾名稱都認。

## 資料夾與檔案

| 中文 | 英文 |
|---|---|
| 關注 | `watches/` |
| 觀測 | `observations/` |
| 標註 | `annotations/` |
| 實體表 | `entities.jsonl` |
| 狀態 | `states/` |
| 變化 | `changes/` |
| 報告 | `reports/` |
| 回饋 | `feedback.jsonl` |
| 設定 | `config.yaml` |

## 名詞

| 中文 | 英文 | 意思 |
|---|---|---|
| 觀測 | observation | 收集器抓到的一筆原始資料 |
| 標註 | annotation | 程式對一筆觀測的判讀：相關性、實體、事件、story |
| 來源類型 | source | `news` 新聞、`forum` 論壇／社群、`shop` 電商、`search` 搜尋熱度、`industry` 產業網站 |
| 網站 | site | 具體的網站或看板 |
| 轉載組 | story | 同一則消息的所有轉載，統計時只算一次 |
| 實體 | entity | 要追蹤的對象：品牌、產品、成分、話題、服務 |
| 別名 | alias | 同一個實體的其他寫法 |
| 提及 | mention | 一筆觀測提到某個實體 |
| 事件 | event | 原文明確寫出的事：上市、回收、停產等 |
| 狀態 | state | 一個實體某一天的快照 |
| 基準線 | baseline | 「平常」的數量，用來比較 |
| 成長倍數 | growth | 近期 ÷ 基準，各加 1 |
| 變化 | change | 值得報告的差異 |
| 熱門 | hot | 2 種以上來源類型同時上升 |
| 待觀察 | watch-only | 只有單一來源類型上升 |
| 關注 | watch | 一個要追蹤的市場範圍 |
| 探針 | probe | 由相關、不相關例子算出的方向，用來給觀測打相關分數 |
| 回饋 | feedback | 你在報告上的標記 |

## 標記

| 中文 | 用在 | 意思 |
|---|---|---|
| 追 | 變化 | 值得追蹤 |
| 雜訊 | 變化 | 不是真的變化 |
| 確認 | 實體 | 這是一個新的實體 |
| 合併 | 實體 | 這是另一個實體的別名 |
| 忽略 | 實體 | 不追蹤 |
| 相關／不相關 | 觀測 | 屬不屬於這個關注 |
