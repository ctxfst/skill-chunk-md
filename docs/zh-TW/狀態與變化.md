# 狀態與變化

**狀態**是每個實體每天的一張快照。**變化**是把今天的狀態和過去比較後，程式認為值得你看的差異。

> 範例中的品牌與數字都是虛構的。

## 每日狀態（`狀態/日期.jsonl`）

每個在追蹤中的實體，每天一行。

```json
{
  "date": "2026-10-13",
  "entity": "product:霧光-b5-修護霜",
  "watch": "化妝品",
  "mentions": {"news": 2, "forum": 9, "industry": 0, "shop": 0},
  "stories": 8,
  "source_types": 2,
  "sentiment": {"正面": 6, "負面": 1, "中性": 1},
  "interest": 64,
  "shop": {"rank_best": 3, "price_min": 399, "sold": 15200, "sold_delta": 180, "reviews": 2310},
  "evidence": ["obs:3f9a1c0e7b2d", "obs:a71c22d90e4f"]
}
```

| 欄位 | 說明 |
|---|---|
| `mentions` | 各種來源類型裡，提到這個實體的 **story 數**（重複轉載只算一次）。 |
| `stories` | 不同 story 的總數。 |
| `source_types` | 有提到它的來源類型數，例如新聞和論壇都有就是 2。 |
| `sentiment` | 各種語氣的提及數。 |
| `interest` | 當天的搜尋熱度，沒有資料就省略。 |
| `shop` | 電商數字。`rank_best` 是各平台中最好的名次，`price_min` 是最低售價，`sold_delta` 是和前一天相比的銷量增加。 |
| `evidence` | 支持這筆狀態的觀測 ID，報告裡用來附連結。 |

沒有任何資料的日子不寫這一行。計算時，缺少的日子當作 0 次提及；電商數字則沿用最近一次的值，並記住它已經幾天沒更新。

## 基準線

判斷「變多了」需要先知道「平常是多少」。基準線是**過去 28 天**的平均，不含最近 7 天。

- **近期**：最近 7 天的合計。
- **基準**：再往前 28 天的每 7 天平均。
- **成長倍數** = (近期 + 1) ÷ (基準 + 1)。加 1 是為了避免從 0 變成 1 就被算成無限大。

天數可以在 `設定.yaml` 調整。

## 變化的種類（`變化/日期.jsonl`）

| 種類 | 什麼時候產生 |
|---|---|
| `新出現` | 實體的 `first_seen` 在最近 7 天內，而且已經有 2 個以上的 story。 |
| `上升` | 提及數或搜尋熱度的成長倍數 ≥ 2，而且近期至少 3 個 story。 |
| `下滑` | 成長倍數 ≤ 0.5，而且基準期每週至少 3 個 story（原本就沒什麼人提，就談不上下滑）。 |
| `數值變動` | 電商數字有明顯變化：售價變動 ≥ 10%、名次進出前 10 名、7 天銷量增幅是平常的 2 倍以上。 |
| `事件` | 標註中出現原文明確寫出的事件，例如回收、上市、停產。 |
| `口碑轉向` | 近期負面提及的比例比基準期高 20 個百分點以上，而且近期至少 5 個 story。 |

所有門檻都在 `設定.yaml`，上表是預設值。

```json
{
  "id": "chg:2026-10-13:product:霧光-b5-修護霜:上升",
  "date": "2026-10-13",
  "entity": "product:霧光-b5-修護霜",
  "watch": "化妝品",
  "kind": "上升",
  "level": "熱門",
  "numbers": {"recent": 23, "baseline": 4.5, "growth": 4.3, "source_types_rising": 2},
  "summary": "最近 7 天論壇與新聞的提及數是平常的 4.3 倍，蝦皮名次升到第 3。",
  "evidence": ["obs:3f9a1c0e7b2d", "obs:5b02e6c41a9d", "obs:a71c22d90e4f"],
  "first_reported": "2026-10-11"
}
```

| 欄位 | 說明 |
|---|---|
| `kind` | 變化種類，見上表。 |
| `level` | 只用於 `上升`：`熱門` 或 `待觀察`，見下一節。 |
| `numbers` | 判定時用到的數字，讓你能自己核對。 |
| `summary` | 一句話說明。由數字產生，不加推測。 |
| `evidence` | 最多 5 筆代表性的觀測，各取不同 story。 |
| `first_reported` | 同一個變化第一次出現在報告的日期。持續中的變化不會每天重新當成新的。 |

## 「熱門」怎麼判定

一個實體的變化是 `上升`，還要分成兩級：

- **熱門**：至少 **2 種來源類型**同時上升（例如論壇和電商都升），或其中一種是搜尋熱度上升。
- **待觀察**：只有單一來源類型上升。常見原因是一篇業配文、一次促銷、一則被大量轉貼的貼文。

理由：單一來源的暴增很常見，大多數是雜訊；不同類型的來源各自出現同樣的訊號，才比較像真的需求在變化。

## 一個變化會持續多久

- 條件持續成立，就沿用同一個變化 ID，報告裡標「持續中，第 N 天」。
- 條件連續 3 天不成立，就視為結束。之後再成立，算一個新的變化。
